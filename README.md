# Project
This project is in light of incorporating concepts of C++ programing into use, 
for someone learning C++ from the ground up, with a bit of knowledge in language C.
It specializes in the concepts of OOP.

# ⚔️ Theme
This project revolves around a text turn-based RPG in which you'll play as a player against a bot.
Both the player and bot get stats for health, damage dealing power and number of potions to heal up.
It's up to you to decide the best strategy to win this battle! 

# 📖 How to use
You'll have to select a mode of difficulty of the bot in which you'll play against, using the commands E, N, H 
for Easy, Normal and Hard difficulties respectively.
A stat line will show up and you'll have to decide whether to attack the monster (A) or heal your hp (H).

# 💡 Key take aways in this project
This small program helped me understand better the concepts of OOP and its use cases.
Also improved my hability to move away from the standard C programming into a more C++ view of things
